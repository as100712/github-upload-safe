# GitHub Upload Notes

This folder is the lightweight upload version.

- Video and audio files are removed to avoid GitHub web upload failures.
- The largest file should stay under 1 MB.
- Upload the contents of `github-upload-safe`, not the parent `Documents/3` folder.
- Do not upload `.git`, `node_modules`, cache folders, temporary files, logs, or source project files.

If you need to show videos later, upload them to a video platform or use Git LFS from a local Git clone instead of GitHub's web uploader.
